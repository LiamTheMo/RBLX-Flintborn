# Flintborn

**Flintborn** is a Roblox primitive-fantasy survival sandbox / PvPvE extraction game. Gather and craft stone and metal gear, build and raid tribal forward bases, contest world events and ancient bosses, then extract loot into a persistent vault. Combat uses primitive weapons and elemental magic—**no firearms**.
