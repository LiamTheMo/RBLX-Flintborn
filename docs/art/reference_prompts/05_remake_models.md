## How to use

1. Open a **new chat** and paste everything inside the box below.
2. **Attach a style sample** to that first message: your favourite of the sheets the generator has made recently. Everything it makes will copy that sample's rendering.
3. For each sheet, **attach the original sheet** (`art/blender/assets/references/<number>.png`) and type `next`. The generator keeps that sheet's design and redraws it in the new style. Lobby items (302–336) have no single sheet: attach the lobby group sheet named in the list (for example `art/reference/03_furnishings.png`) instead.
4. Type `redo: <what to fix>` to redo the current sheet, or `skip` to move on.
5. Save each image as `art/blender/assets/references/v2/<number>.png`.
