# v0.05 — Gathering, inventory and field crafting

> **Depends on:** v0.04 · **GDD sources:** §4.1–4.2, §4.4, §7.6 (Q112), §16.8 (Q103/Q105, Q138), §19.1–19.2, §22.1.1 (Q108, Q126–131), §38.2

## Objective

Let an active player harvest wood, stone, iron, fiber, herbs and food from respawning nodes, hold them in a fixed 9-slot hotbar and 50-slot backpack, and craft their first useful gear set within about ten minutes. Advanced gear needs a workbench, where world workbenches give small quality rolls.

## Player-facing result

- Trees, rocks, ore and plant nodes that can be harvested with the right tool, then regrow about two minutes later.
- A **9-slot hotbar** and a **50-slot backpack**. Every unit of one material shares one slot with a total count. Each weapon, tool or armor piece has its own slot.
- A crafting menu with **basic recipes usable anywhere** (wood spear, stone tools, bandages, basic bow, arrow bundle).
- A placeable **workbench** for advanced recipes. Crafting at a world workbench can roll **up to ±5%** on the item's stats.
- Item tooltips show the item's fixed rarity (Common → … → Exclusive) and its individual quality roll.

## Confirmed rules

- **Gathering is harvesting**, not a survival meter (Q25): cutting trees, mining stone and ore, picking herbs and shrubs, harvesting crops and collecting creature hides/bones.
- **Small starting resource catalog** (Q104): wood, stone, iron, fiber, hides, food/herbs and a few creature/event ingredients.
- **Ordinary nodes regrow after ~120 s.** Rare event nodes spawn once per event and never regrow (Q112). Event spawning arrives in v0.11.
- **Inventory:** **9** hotbar slots, **50** backpack slots. **One logical slot per ordinary material type** with one consolidated quantity. Unique gear is always a separate instance (Q108, Q126–128).
- **Carry any combination of weapons** within slot limits (Q131).
- **Launch weapon families:** spears, daggers, swords and bows, plus basic tool and rock attacks (Q100). **Armor slots:** Head, Chest, Legs/Boots; no shields (Q101).
- **Rarity is fixed per item archetype** (e.g. Common Stone Sword, Rare Iron Sword) and is never rolled (Q102).
- **Quality rolls:** an instance may deviate **up to ±5%** from its catalog stats. **Lobby workbenches always give default quality**; world workbenches roll (Q103, Q105, Q138).
- **Best-roll chance** grows **5% relative per Crafting mastery level**: `p × (1 + 0.05 × level)`. It is never +5 percentage points (Q139). Mastery levels themselves arrive in v0.13; level 0 until then.
- **Basic recipes craft anywhere**; advanced gear needs a workbench (Q105). **First gear set in ≤10 minutes** using a few harvested materials (Q106).
- **Every arrow recipe makes 10 arrows**; better arrows need better materials and may deal more damage (Q107).
- **Gear never wears out or breaks** (Q31).
- **Material stacks in the active-world backpack:** the numeric cap is still Open; use the placeholder below.

## Data and persistence

- Run inventory lives in server memory during ActiveRun and is **not** saved as vault content. What happens to it on death, logout or extraction is defined in v0.07 and v0.08.
- Unique instances get server GUIDs with `catalogId`, `qualityRoll`, `sourceStation`, `craftingMasterySnapshot` and `acquisitionId` (GDD §23.2).
- Recipes carry a `version`. A craft records the version it used (§16.4).

## Security and anti-exploit

- Harvest requests are checked for distance, tool tier, node state and a minimum interval. Two players hitting one node cannot both receive its final yield (§7.6).
- The client never chooses stats, rarity, roll or output amount.
- Crafting consumes inputs and creates the output in one server step; repeated requests are idempotent.
- Quantities are positive bounded integers.

## UX and accessibility

- Material slots show one icon with a count. Gear slots show rarity with colour **and** a text/icon label.
- The crafting menu greys out missing inputs and explains which station is needed.
- Drag-and-drop has tap-to-select and controller alternatives; no precision dragging required (§25.4).

## Validation

**Automated specs:**
- material aggregation keeps one slot per type;
- unique items never merge;
- hotbar and backpack never exceed 9 and 50;
- arrow recipes yield exactly 10;
- rolls stay within ±5%;
- best-roll chance is 1.00% → 1.05% → 1.50% for levels 0/1/10 from a 1% base;
- lobby-station crafts always have a 0 roll;
- crafting is idempotent on a repeated request ID.

**Studio checks:**
- Fresh spawn to a full basic set (spear, bow, arrows, bandages) in under 10 minutes.
- Harvest a node to depletion with two players at once: no duplicate yield.
- The node regrows in about 120 s.

## Exit criteria

- [ ] Item catalog, recipes and inventory rules shared and covered by specs.
- [ ] Gathering, crafting and the inventory UI work on desktop, touch and controller.
- [ ] First gear set achievable in ≤10 minutes in a playtest.
