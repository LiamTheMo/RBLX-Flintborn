# v0.11 — World event director and rare spawns

> **Depends on:** v0.10 · **GDD sources:** §7 (all), §18.1, §32.1, §35.3 Q42–48, §38.3 Q111–112, §39.4 Q140–143

## Objective

Make every world feel different. Run a server event director that rolls weighted, publicly announced events about every five minutes: rare plants, ore, elite mobs, meteors, supply caches and generated ruins. They spawn at random valid places in their biome, giving players contested reasons to move across the island.

## Player-facing result

- Server-wide **event announcements** with a sound, a map indicator and a sky beacon, for every event, even small ones.
- **Rare shrubs, trees and ore** that appear once per event at random spots in their biome.
- **Meteor crashes** that need a long, contestable harvest.
- **Ancient Supply Caches** that need **60 continuous seconds** of interaction to open.
- **Elite (alpha) mobs** with escorts, and creature enemies themed as primitive animals, ancient creatures, skeletons, elementals, evil NPCs and mythological beings.
- **Generated raidable structures:** abandoned forts, NPC-defended camps and ruins. None can be claimed by players.

## Confirmed rules

**The director**
- **Tick about every 5 minutes** for non-Guardian events (Q42, Q111).
- **Each eligible category rolls independently** (Q141): rare vegetation, ore, NPC encounter, cache, meteor, generated structure, event boss.
- **Category trigger chance ~25%** (Q140). On success, try rarities **highest first**: **Secret** (~0.1% example), then Mythic, Legendary, Epic, Rare and Uncommon by explicit weights. **Fall back to Common** if the category has one; skip if it doesn't (Q140, §7.1).
- **No fixed limit on simultaneous events**; only spatial footprint separation and the server performance budget limit them (Q142–143).
- **Every actual event is announced publicly**; there are no secret unannounced spawns (Q43).
- **Rare resources spawn at random valid locations within their biome** (Q48), **once per event**, with **no regrowth** (Q112).

**Contents**
- **Enemy themes:** primitive, ancient, skeletal, elemental, evil NPC and mythological (Q44). Elemental enemies give players no magic.
- **Generated structures:** abandoned, NPC-defended and ruins; **never claimable** (Q47).
- **Cache unlock:** 60 continuous seconds; an interrupted channel restarts (§7.4).
- **Event loot is physical and contested** until extracted (§8.2). Event items are handled per item and carry an `"event"` tag (Q161a).

**Exempt from the director:** the Guardian keeps its own schedule (v0.12).

## Data and persistence

None persistent: events, nodes, mobs and ruins are world state. Telemetry counters (spawn frequency by category and rarity, successful extractions of event loot) feed v0.17 analytics (§7.5).

## Security and anti-exploit

- Rolls happen only on the server, with the server's `Random`.
- One-time rare rewards cannot be granted twice by repeated callbacks (§7.6).
- Loot is server-created and claimed once per instance.
- NPC damage uses the same CombatService validation as PvP.

## UX and accessibility

- Announcements combine an icon, text, sound and a direction/area hint.
- Exact marker or regional hint per event type is an Open choice; start with an area circle.
- Rarity is shown with colour **and** its name.
- Beacons must not hide projectiles or extraction signals (§36.5).

## Validation

**Automated specs (`EventRules`, seeded `Random`):**
- each category rolls independently, so several can succeed in one tick;
- about 25% of ticks trigger per category over many trials;
- the waterfall tries Secret first and falls back to Common;
- a category with no Common skips;
- the Secret rate is about 0.025% per category per tick in a large simulation;
- footprint separation rejects overlapping candidates;
- rare nodes never regrow.

**Studio checks:**
- Every event is announced.
- Events spread across biomes.
- A full 30-player server stays within budget during several events at once.
- The cache channel restarts on interruption.
- Event loot is lost on death and only safe after extraction.

## Exit criteria

- [ ] Director runs independent category rolls with the rarity waterfall and Common fallback.
- [ ] Every event is publicly announced and placed in a valid biome location.
- [ ] Caches, meteors, elites and generated structures playable.
