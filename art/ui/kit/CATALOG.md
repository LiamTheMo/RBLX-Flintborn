# Lobby kit sprites (`lk_*`)

Generated by `art/ui/slice_lobby_kit.py` from the kit sheets in `art/reference/ui/lobby/kit/`; re-run the script instead of editing this file. Sprites are in `art/ui/sprites/lk_*.png` and in `art/ui/sprites/manifest.json` (`w`, `h`, `slice` = 9-slice insets `[left, top, right, bottom]` in pixels).

Contact sheets: `contact_dark.png` (on #202020) and `contact_light.png` (on #F0E6D2) show every sprite at 1x with a 0.5x copy (straight-alpha bilinear, the way the GPU samples it). `slice_test.png` shows each sliced sprite at its stored size (cyan box = slice centre) and stretched to three other sizes.

## Using them

- Sizes are design pixels of the 1672x941 mockups: show a sprite at its stored size for the mockup look. Small icons are stored up to about 1.5x their largest on-screen size.
- 9-slice: `ScaleType = Slice`, `SliceCenter = Rect(l, t, w - r, h - b)`, `SliceScale = 1` at design resolution (scale it with the UI scale). Corners, rivets and ornaments lie inside the insets.
- "Stretch" = the axis a sliced sprite may grow along; X-only parts carry a glyph or arrow centred vertically in their side insets, so set their height to the stored height.
- Text, numbers and placeholder icons were painted out of the parts that had them; draw them natively.
- Glyphs (`lk_glyph_*`) are dark brown (white for `glyph_play` / `glyph_check_white`); tint with `ImageColor3` if needed.
- Sprites the game uses are packed by `art/ui/pack_atlas.py` into the `atlas_lk_*` atlases ("Atlas" column; manifest `atlas` / `rect`). Unused sprites stay as files in no atlas. Re-running this script keeps each placement while the sprite's size is unchanged; run `pack_atlas.py` after any size change.
