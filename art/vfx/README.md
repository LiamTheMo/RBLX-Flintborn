# Flintborn VFX

Particle textures and emitter specs for the live effects: fire, sparks, embers, smoke, glows, rune motes, waterfall mist and splash, water foam and dust. Everything here is generated by [`art/blender/scripts/build_08_vfx.py`](../blender/scripts/build_08_vfx.py) from the specs in [`art/blender/lib/vfx.py`](../blender/lib/vfx.py):

```bash
"D:/Steam/steamapps/common/Blender/blender.exe" --background --factory-startup --python art/blender/scripts/build_08_vfx.py
```

Set `FX_ONLY=tex` or `FX_ONLY=preview` to run only one half.

| Path | Contents |
| --- | --- |
| `textures/<name>.png` | Particle textures: square, RGBA, transparent background. |
| `vfx_catalog.json` | `vfx.catalog()`: textures, the 12 kinds (emitters and light) and which assets carry which sockets. |
| `../blender/renders/08_vfx.png` | Preview sheet: stand-in bases with realized sockets, studio light. |
| `../blender/renders/08_vfx_dim.png` | The same sheet with the studio dimmed so the point lights read. |
| `../blender/renders/08_vfx_textures.png` | Contact sheet of every texture on a dark ground. |
| `../blender/assets/08_vfx_preview.blend` | The preview scene (bases, sockets, `VFX Preview` collection). |

Preview sheet order, left to right and top to bottom: torch head (`torch_fire`), fire ring (`campfire`), brazier bowl (`brazier_fire` + `embers`), furnace arch (`forge_fire` + `heat_glow` + `glyph_glow`), chimney stack (`chimney_smoke`), rune slab (`rune_glow`), waterfall drop (`waterfall_mist` + `water_foam`), shoreline (3 × `water_foam`) and dirt patch (`dust`).

## Textures

| Texture | Size | Tint | Look | Used by |
| --- | --- | --- | --- | --- |
| `fire_flipbook_4x4` | 1024 (16 × 256) | colour | Seamless 16-frame loop of a chunky faceted flame. It has a pale-yellow core, an orange body and red-orange tips. Tongues bob and sway, and small diamond fragments split off the tips, rise and shrink away. | all fire kinds |
| `spark_diamond` | 256 | white | A faceted 4-point diamond with a faint halo. | campfire, forge |
| `ember_dot` | 128 | white | A faceted octagon dot with a soft halo. | torch, brazier, embers |
| `glow_soft` | 256 | white | A radial soft glow. | heat_glow, glyph_glow, crystal_halo |
| `rune_mote` | 256 | pale blue | A lozenge rune glyph with a star glint and a pale-blue halo. | rune_glow |
| `smoke_puff` | 256 | white-grey | A cluster of faceted puffs with soft, fading edges. | campfire, chimney |
| `mist_soft` | 512 | white | A large, very soft mist blob. | waterfall_mist |
| `splash_droplets` | 256 | white | A crown of faceted teardrop droplets over a low splash mound, with spray dots. | waterfall_mist |
| `foam_patch` | 512 | white | Flat foam swirl bands and bubbles seen from above, over a faint wash. | water_foam |
| `dust_mote` | 128 | white | A tiny soft hexagon mote. | dust |

"White" textures are greyscale, so the emitter's `Color` sequence sets their final colour. The flipbook and the rune mote carry their own colours, so their `Color` stays near white and only warms or cools them over life. Fully transparent pixels have their colour bled outward, and each flipbook cell has a clear 2 px border, so bilinear filtering never pulls in black or a neighbouring frame.

### Upload, then swap in asset ids

The PNGs are not usable in Studio until they are uploaded:

1. Upload each PNG: use Asset Manager > Bulk Import, or Create > Decals and copy the *image* id, not the decal id.
2. Record each `rbxassetid://<id>` against its texture name. For example, keep a `VfxTextures` ModuleScript `{ fire_flipbook_4x4 = "rbxassetid://…", … }`.
3. Wherever a spec says `"texture": "<name>"`, set `ParticleEmitter.Texture` to that id.

Re-uploading a re-rendered PNG gives a new id, so update the module whenever the textures change.

## Sockets

Each asset carries Empties named `VFX_<kind>`, parented to the mesh at the emitter position. Their custom properties are:

- `vfx_kind`: one of the kinds below (`vfx.KINDS`).
- `vfx_scale`: a size multiplier (1.0 is tuned for the kind's typical asset).
- `roblox`: the JSON spec (emitters and light).

On export, turn each socket into an **Attachment** at the same position, holding the emitters and the light. An emitter with a `shape` needs an invisible, non-colliding, anchored **Part** of that size instead (`Transparency = 1`, `CanCollide/CanQuery/CanTouch = false`), with `ParticleEmitter.Shape = Box` and `ShapeStyle = Volume`. A box that is thin on one axis gives a flat emission area: use it for foam along a shore line, or for mist across a plunge pool. Blender's `(x, y, z)` maps to Roblox `(x, z, -y)`, but the spec values are already in Roblox axes.

**Scale:** multiply `Size`, `Speed`, `Acceleration`, `shape` and the light `Range` by `vfx_scale`.

### Spec → ParticleEmitter

| Spec key | ParticleEmitter property | Notes |
| --- | --- | --- |
| `texture` | `Texture` | The uploaded asset id (see above). |
| `flipbook: "4x4"` | `FlipbookLayout = Grid4x4`, `FlipbookMode = Loop`, `FlipbookFramerate = NumberRange.new(16, 22)` | Frames run left to right, top to bottom. Set `FlipbookStartRandom = true` so neighbouring flames don't pulse in step. |
| `color` | `Color` (ColorSequence) | Evenly spaced keypoints from birth to death (2 → 0, 1; 3 → 0, 0.5, 1). |
| `size` | `Size` (NumberSequence) | Same keypoint spacing. Values are studs, × `vfx_scale`. |
| `transparency` | `Transparency` (NumberSequence) | Same keypoint spacing. |
| `lifetime` | `Lifetime` (NumberRange min, max) | |
| `rate` | `Rate` | Particles per second. |
| `speed` | `Speed` (NumberRange) | × `vfx_scale`. |
| `spread` | `SpreadAngle = Vector2.new(spread, spread)` | Degrees around `EmissionDirection = Top`. |
| `light_emission` | `LightEmission` | 1 is additive, for fire, sparks and glows. 0 is normal blending, for smoke and foam. |
| `acceleration` | `Acceleration` (Vector3) | Roblox axes; Y is up. × `vfx_scale`. |
| `drag` | `Drag` | Sparks and embers decelerate, so they hang above the fire instead of shooting off. |
| `rotation`, `rot_speed` | `Rotation`, `RotSpeed` (NumberRange, degrees) | |
| `orientation: "flat"` | `Orientation = VelocityPerpendicular` | Velocity is up, so the particle lies flat on the water (foam). Every other emitter uses the default `FacingCamera`. |
| `shape` | Parent Part size (Roblox X, Y, Z studs) | `Shape = Box`, `ShapeStyle = Volume`. |

Also set `LightInfluence = 0` on emissive emitters (`light_emission` ≥ 1), so the night lighting doesn't darken fire, and `LightInfluence = 1` on smoke, mist and foam. Set `ZOffset` to about 0.5 on fire, so it sorts in front of the asset's own mesh flame.

### Spec → PointLight

| Spec key | PointLight | Notes |
| --- | --- | --- |
| `light.color` | `Color` | |
| `light.brightness` | `Brightness` | |
| `light.range` | `Range` | × `vfx_scale`. |
| `light.flicker` | Script | A random wobble of about ±25 % on Brightness, at about 8–12 Hz. |
| `light.pulse` | Script | A slow sine of about ±25 % on Brightness, with a 2–4 s period. |
| (none) | `Shadows = false` | Cheap, and the asset's own flame mesh would otherwise block the light. |

Flicker and pulse belong in one client script over every tagged light. Run it on the client so it costs nothing on the server:

```lua
-- StarterPlayerScripts/VfxLights.client.lua: tag lights "VfxFlicker" or "VfxPulse"
local CollectionService = game:GetService("CollectionService")
local RunService = game:GetService("RunService")
local lights = {}
local function track(light, mode)
	lights[light] = { base = light.Brightness, mode = mode, seed = math.random() * 100 }
end
for _, mode in { "VfxFlicker", "VfxPulse" } do
	for _, l in CollectionService:GetTagged(mode) do track(l, mode) end
	CollectionService:GetInstanceAddedSignal(mode):Connect(function(l) track(l, mode) end)
	CollectionService:GetInstanceRemovedSignal(mode):Connect(function(l) lights[l] = nil end)
end
RunService.Heartbeat:Connect(function()
	local t = os.clock()
	for l, s in lights do
		local k = if s.mode == "VfxFlicker"
			then 1 + 0.25 * math.noise(t * 9, s.seed) + 0.08 * math.sin(t * 23 + s.seed)
			else 1 + 0.25 * math.sin(t * 2.2 + s.seed)
		l.Brightness = s.base * k
	end
end)
```

## Blender preview

`vfx.realize(scene=None, objects=None, particles=True)` turns sockets into preview effects, all named `VFXPreview_*` in a `VFX Preview` collection and parented to their socket:

- **Light:** a point light per socket whose kind has a `light`. It uses the light's colour, energy = 1.4 W × brightness × range², custom distance = 1.5 × range (where the Eevee build supports it) and no shadows. Its energy driver (expression `frame`, so it runs without Python auto-run) has a constant generator plus a Noise modifier (flicker, about ±25 %) or a sine (pulse).
- **Stand-ins** (`particles=True`): one merged mesh per emitter. Each is a still frame of that emitter, simulated from its speed, spread, drag, acceleration, shape, size, colour and transparency, up to 12 particles. Sparks become emissive diamonds, embers and motes small emissive gems, smoke translucent faceted puffs, glows soft emissive blobs, mist a translucent white mound, splash teardrop droplets, and foam flat swirl crescents on the water. Flipbook flames get no stand-in, because the asset mesh already carries the flame.

It is idempotent: re-running replaces the previous previews, and passing `objects` replaces only those assets' previews. `vfx.clear(scene)` removes them all. The materials are blended, not dithered, so the viewport stays clean and cheap. For the lobby's ~40 sockets that is roughly 40 lights and 60 small meshes.
